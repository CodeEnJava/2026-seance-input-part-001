## 📖 Présentation

Cette séance pédagogique a pour objectif d'introduire la fonction `input()` et de permettre aux apprenants de créer leurs premiers programmes interactifs en Python.

Les exercices proposés s'appuient sur l'ensemble des notions étudiées lors des séances précédentes afin de consolider les acquis à travers des cas pratiques simples et progressifs.

---

## 📋  Prérequis

Avant de réaliser cette séance, les apprenants doivent avoir validé les compétences suivantes :

| Référence   | Thème                                        |
| ----------- | -------------------------------------------- |
| S-PYTH-1002 | Utiliser Python comme une machine à calculer |
| S-PYTH-1003 | Division entière (`//`) et modulo (`%`)      |
| S-PYTH-1004 | Manipulation des variables numériques        |
| S-PYTH-1006 | Manipulation des chaînes de caractères       |
| S-PYTH-1007 | Manipulation de la fonction `print()`        |

---

## 🎯 Objectifs pédagogiques

À l'issue de cette séance, l'apprenant sera capable de :

* Utiliser la fonction `input()` pour récupérer des données saisies au clavier.
* Stocker les données saisies dans des variables.
* Manipuler des chaînes de caractères provenant d'une saisie utilisateur.
* Convertir une chaîne de caractères en valeur numérique avec `int()` ou `float()`.
* Réaliser des calculs à partir de données fournies par l'utilisateur.
* Développer des scripts interactifs simples.

## 📚 Contenu de la séance

### Découverte de la fonction `input()`

* Fonctionnement général de la saisie clavier.
* Utilisation avec et sans message d'invite.
* Analyse du type de données retourné.

### Exercices d'application

#### Exercice 1 — Bonjour utilisateur

Création d'un programme qui :

* demande le prénom de l'utilisateur ;
* normalise la saisie (minuscules puis première lettre en majuscule) ;
* affiche un message de bienvenue personnalisé.

#### Exercice 2 — Générateur de pseudo

Création d'un programme qui :

* récupère un nom et un prénom ;
* extrait les trois premières lettres de chacun ;
* génère automatiquement un pseudo utilisateur.

#### Exercice 3 — Résolution d'une équation du premier degré

Création d'un programme permettant de résoudre une équation de la forme :

```text
ax + b = 0
```

à partir des valeurs saisies par l'utilisateur.

#### Exercice 4 — Calcul d'âge

Création d'un programme qui :

* récupère l'identité d'un utilisateur ;
* demande son année de naissance ;
* calcule et affiche son âge.
